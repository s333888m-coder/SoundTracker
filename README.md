# Futuristic Sound — Redmi Note 13 5G (HyperOS 3.0.3.0 / Android 15)

## GitHub Actions से APK कैसे बिल्ड करें:
1. GitHub पर नई Repository बनाएं (e.g., `FuturisticSound-HyperOS`).
2. इस ZIP की सभी फाइलों को Repository के root में upload/push करें।
3. GitHub के **Actions** टैब में जाएं और **Build Futuristic Sound APK** वर्कफ़्लो को पूरा होने दें।
4. **Artifacts** से `FuturisticSound-HyperOS3-APK` डाउनलोड करें और अपने Redmi Note 13 5G में इंस्टॉल करें।

## HyperOS 3.0.3.0 पर सेटअप (No Developer Mode Required):
- Settings > Additional Settings > Accessibility > Downloaded Apps > **Futuristic Sound** ON करें।
- Notification Access में **Futuristic Sound** ON करें।
- App Info > Autostart ON करें और Battery Saver को **No Restrictions** पर सेट करें।
- अगर कोई Swipe Back या सिस्टम जेस्चर कैच न हो, तो ऐप में **Floating Event Catcher HUD** ON करें और उस जेस्चर को लाइव कैच करके तुरंत साउंड बाइंड करें!
